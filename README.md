# 🍽️ Mess Meal Management System (মেস মিল ম্যানেজমেন্ট সিস্টেম)

একটি আধুনিক, সুরক্ষিত ও স্বয়ংক্রিয় মেস মিল ও হিসাব ব্যবস্থাপনা ওয়েব অ্যাপ্লিকেশন। এটি ব্যাচেলর মেস, হোস্টেল ও শেয়ার্ড অ্যাপার্টমেন্টের দৈনিক মিল কাউন্ট, বাজার খরচ, ইউটিলিটি বিল এবং মাসিক ফিনান্সিয়াল রিপোর্ট পরিচালনার জন্য বিশেষভাবে তৈরি।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### 👥 মাল্টি-রোল অ্যাক্সেস কন্ট্রোল (Multi-Role System)
- **Super Admin (সুপার অ্যাডমিন):** নতুন মেম্বার অনুমোদন, ম্যানেজার নিয়োগ, নতুন মাস তৈরি ও বন্ধ (Close/Archive) করা এবং সম্পূর্ণ ডাটাবেজ নিয়ন্ত্রণ।
- **Manager (ম্যানেজার):** কুকিং বোর্ড পরিচালনা, মিল লক, দৈনিক বাজার এন্ট্রি, ইউটিলিটি বিল যোগ এবং মেম্বারদের ডিপোজিট সংগ্রহ।
- **Member (মেম্বার):** প্রতিদিনের মিল বুকিং (সকাল, দুপুর, রাত ও গেস্ট মিল), নিজের জমা-খরচ ও মেসের সার্বিক লাইভ হিসাব পর্যবেক্ষণ।

### 🍳 রান্নার লাইভ কুকিং বোর্ড (Kitchen Cooking Board)
- **লাইভ মিল সামারি:** কোন বেলায় মোট কত মিল রান্না হবে (রেগুলার সদস্য + গেস্ট মিল) তার তাৎক্ষণিক হিসাব।
- **আলাদা সেশন লক:** রান্নার সুবিধার্থে সকাল, দুপুর বা রাতের মিল আলাদা আলাদা সময়ে লক করার সুবিধা (মেম্বাররা লক হওয়া বেলার মিল পরিবর্তন করতে পারবেন না)।
- **কাস্টম মিল ওয়েট:** সকাল ($0.5$), দুপুর ($1.0$), রাত ($1.0$) ও গেস্ট মিলের মান যেকোনো সময় পরিবর্তনযোগ্য।

### 📊 গুগল শিট ইন্টিগ্রেশন ("Add to Sheet" অন-ডিমান্ড সিঙ্ক)
- **সাইট-অনলি বুকিং:** মেম্বারদের দৈনিক বুকিং এবং লকের হিসাব সাইটেই সংরক্ষিত থাকে, ফলে অপ্রয়োজনীয় ডাটা শিটে জমা হয় না।
- **এক ক্লিকে শিটে যোগ:** রান্না শেষে ম্যানেজার **"➕ শিটে যোগ করুন (Add to Sheet)"** বাটনে ক্লিক করলে স্বয়ংক্রিয়ভাবে গুগল শিটের **Meals** ট্যাব এবং মাসিক ভিজ্যুয়াল ট্যাবে যুক্ত হয়ে যায়।
- **সিঙ্গেল মান্থলি শিট:** প্রতিটি মাসের জন্য স্বয়ংক্রিয়ভাবে আলাদা ট্যাব (যেমন `2026-10`) তৈরি হয় যাতে থাকে:
  1. ৩১ দিনের পূর্ণ মিল ম্যাট্রিক্স ছক
  2. সদস্যভিত্তিক ব্যালেন্স সামারি (মিল রেট, মোট খরচ, জমা, ডিউ/ফেরত)
  3. দৈনিক বাজারের বিস্তারিত তালিকা
  4. ইউটিলিটি বিলের ক্যাটাগরি ও বণ্টন তালিকা

### 🛒 বাজার ও ইউটিলিটি খরচ ব্যবস্থাপনা
- **দৈনিক বাজার লগ:** তারিখ, বাজারকারী সদস্যের নাম, খরচের পরিমাণ ও বিবরণী।
- **নির্দিষ্ট মেম্বার বণ্টন:** ইউটিলিটি বিল (খালা বিল, গ্যাস বিল, ফ্রিজ বিল ইত্যাদি) "সবার মাঝে সমান" অথবা কোনো "নির্দিষ্ট সদস্যের" নামে দেওয়ার সুবিধা।

### 💰 স্বয়ংক্রিয় হিসাব ও মিল রেট (Automated Calculation)
- **ডায়নামিক মিল রেট:** $\text{Mill Rate} = \frac{\text{Total Bazar}}{\text{Total Meals}}$
- **লাইভ ব্যালেন্স:** প্রত্যেক সদস্যের জমা এবং খরচের পার্থক্য অনুযায়ী স্বয়ংক্রিয় `DUE` বা `REFUND` হিসাব।
- **রিপোর্ট প্রিন্ট ও ডাউনলোড:** জেনারেটেড রিপোর্ট প্রিন্ট ও সেভ করার সুবিধা।

## 🛠️ প্রযুক্তিগত কাঠামো (Tech Stack)

- **Frontend & Backend Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **UI Library & Styling:** [React 18](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/), [Lucide React](https://lucide.dev/) Icons
- **Animation:** Framer Motion
- **Database & Sync:** Local JSON Fast Cache + [Google Apps Script (GAS)](https://developers.google.com/apps-script)
- **PDF Generation:** jsPDF & jsPDF-AutoTable

## 🚀 শুরু করার নিয়ম (Getting Started)

### ১. ক্লোন ও ডিপেন্ডেন্সি ইনস্টল
```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/your-username/meal-management-system.git

# প্রোজেক্ট ফোল্ডারে প্রবেশ করুন
cd meal-management-system

# প্যাকেজসমূহ ইনস্টল করুন
npm install
```

### ২. এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ
প্রোজেক্টের রুট ডিরেক্টরিতে `.env.example` ফাইলটি কপি করে `.env.local` তৈরি করুন:

```bash
cp .env.example .env.local
```

`.env.local` ফাইলে আপনার গুগল অ্যাপস স্ক্রিপ্ট ইউআরএল এবং কী দিন:
```env
GAS_API_URL=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
GAS_API_KEY=MILL_SECRET_KEY_2026
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।

## 📑 গুগল শিট ব্যাকএন্ড সেটআপ (Google Sheets Setup)

1. একটি নতুন **Google Spreadsheet** তৈরি করুন।
2. মেনু থেকে **Extensions** ➔ **Apps Script**-এ প্রবেশ করুন।
3. প্রোজেক্টের [`lib/gas/Code.gs`](lib/gas/Code.gs) ফাইলের সম্পূর্ণ কোড কপি করে গুগল অ্যাপস স্ক্রিপ্ট এডিটরে পেস্ট করুন।
4. স্ক্রিপ্টটি সেভ করুন (**Ctrl + S**)।
5. ওপরের ডানদিকের নীল **Deploy** বাটনে ক্লিক করুন ➔ **New deployment**:
   - **Select type:** Web app
   - **Execute as:** Me (your Google account)
   - **Who has access:** Anyone
   - **Deploy** বাটনে ক্লিক করুন।
6. প্রাপ্ত **Web app URL** টি কপি করে আপনার `.env.local` ফাইলের `GAS_API_URL`-এ বসিয়ে দিন।
